# DriftBottle 🍾🌊

A message in a bottle, thrown into the sea of GitHub.

Open a pull request. Leave a note. Let the tide carry it somewhere.

## How to leave a message

1. **Fork** this repository.
2. In your fork, add a file under `messages/` named `your-github-username.md`.
3. Write anything: a thought, a poem, a question, a confession, a line you can't get out of your head. One message per bottle.
4. Open a **pull request** with the title `Bottle: <your name>`.
5. The bottle gets picked up, merged, and drifts on.

That's it. No code required — just words.

## Where the bottles go

Every merged message lives in [`messages/`](messages/). Read them all, or just the ones that call to you.

## The rules of the sea

- Be kind. Be honest. No spam, no ads, no hate.
- One message per person (you can send more than one bottle, just not all at once).
- Messages are permanent — the sea doesn't give things back.
- Your message is yours; the drift is everyone's.

## Why?

Because sometimes the best way to say something is to throw it into the ocean and trust that someone, somewhere, will find it.

> *"These fragments I have shored against my ruins."* — T.S. Eliot, *The Waste Land*
